## 1. 现状说明

- **当前状态**：仓库根目录暂无 `LICENSE` 文件。
- **法律影响**：在未声明开源许可证的情况下，默认版权状态为**「保留所有权利（All Rights Reserved）」**。外部开发者即使能看到公开源码，在严格法律意义上也无法自由分发、修改或集成。
- **社区要求**：Linux.do 官方《关于开源推广类主题的补充公告》要求分享的项目必须具有明确的开源协议；若无许可证，无法通过「开源推广」合规核验。

## 2. 代码许可证候选方案

| 许可证选项 | 特点与优势 | 潜在影响 | 适用推荐度 |
|---|---|---|:---:|
| **MIT License** | 最宽松、最流行；允许任何人免费商用、修改、分发；仅需保留原始版权声明。 | 衍生闭源不受限制。 | **★★★★★（首选推荐）** |
| **Apache 2.0** | 宽松度接近 MIT，但增加了明确的**专利授权条款**与**商标使用限制**，更严谨。 | 文本较长，声明稍复杂。 | **★★★★☆（备选）** |
| **GPL v3 / AGPL v3** | 强互惠（传染性）协议；要求任何修改和基于此构建的项目也必须开源。 | 不利于轻量级工具传播，商用开发者常会避开。 | **★★☆☆☆（不推荐）** |

## 3. 资产分类与授权边界（关键原则：代码与素材分离）

本项目包含两大类资产，**必须在法律层面做明确区分，不得将第三方图片素材混为宽松开源协议**：

1. **自主代码资产（Source Code）**：
   - 包含：`index.html` 交互与样式、`backend/` GoFrame 后端适配代码、`docker-compose.yml` 编排文件、自动化脚本等。
   - 建议授权：**MIT License**（由项目所有者全权决定并签署）。
2. **服装图集与数据资产（Costume Images & Data）**：
   - 包含：`data.js` 服装元数据、`assets/thumbs/` 缩略图、`assets/img/` 展示大图。
   - 素材来源：源自 X 推文作者 [@giaaibusi](https://x.com/giaaibusi) 的整理与创意。
   - 许可约束：**可免费用于作品创作（含个人商业创作、设计参考），但禁止将图像数据本身（原尺寸或加工后）打包再分发、转载与直接销售。**
   - **重要提示**：此部分素材**不可**声明为 CC0 或 MIT，必须保持专属使用许可。

## 4. 所有者行动指南（如何一键解锁）

若所有者确认采用 **MIT License**，只需执行以下操作：

1. 在仓库根目录新建 `LICENSE` 文件。
2. 粘贴标准 MIT License 文本（将版权人替换为项目所有者名称与 2026 年份）。
3. 在 `README.md` 中注明：
   ```markdown
   ## 📄 许可证

   - **代码（Code）**：基于 [MIT License](LICENSE) 开源。
   - **图像与素材（Assets）**：遵循 [专属创作使用许可](#-使用许可)，禁止打包再分发与销售。
   ```
4. 完成上述操作后，即可在 `docs/LINUXDO_PUBLISH_CHECKLIST.md` 中将许可证核验项更新为 `[x]` 并满足开源分享条件。
